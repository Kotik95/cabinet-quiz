SIR JAMES'S QUIZBOX — VERSION 7

Changes:
- New filled gold British Shorthair silhouette logo.
- Fluid requestAnimationFrame timer animation using GPU-friendly transforms.
- Questions reveal immediately when every connected player has answered.
- If anyone has not answered, the full 20-second timer remains available.

Deployment:
1. Replace the contents of your existing Quiz folder with these files.
2. Commit the changes in GitHub Desktop.
3. Push origin.

Firebase rules are unchanged from Version 6 and do not need to be republished.
