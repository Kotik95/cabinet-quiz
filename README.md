# Cabinet Quiz — English Edition

A mobile multiplayer general-knowledge quiz built for iPhone and modern browsers.

## Included
- 100 English questions across 10 categories
- Firebase anonymous authentication and Realtime Database multiplayer
- Five questions per round
- Speed-based bonus scoring
- Shareable room links
- Installable web app support

## Publishing updates
Replace the files in your existing local repository, commit the changes in GitHub Desktop, and push to `main`. GitHub Pages will update automatically.
